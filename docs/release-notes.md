Agent Relay 0.3.2 · macOS 26+ · Apple Silicon

减少界面资源保留：关闭设置及本地会话后释放窗口，菜单按需创建，额度未变化时复用账号行。手动操作成功提示 3 秒后自动消失。

到期时间与 Pro · 重置卡数量保持同一行；菜单中的设置、检查更新位于菜单栏显示、刷新额度之后。

新增设置页：主窗口齿轮和菜单栏均可打开，统一管理透明度、菜单栏额度显示、额度周期及更新选项。

接入 Sparkle 2：默认每天检查更新，可手动检查并确认下载安装。更新包使用 Ed25519 签名，安装前等待账号操作完成并关闭管理窗口，保留账号与会话。v0.3.0 以前的版本需先手动安装一次此版本。

显示每个账号可用重置卡的最近到期时间：过滤已使用及已过期的卡，零张卡或未提供到期时间时隐藏；只返回部分卡详情时标为“已知最近到期”。主窗口和菜单栏同步显示。

此版本仍采用临时代码签名，未进行 Apple 公证；Sparkle 更新包签名与 Apple Developer ID 签名不同。
