Agent Relay 0.2.3 · macOS 26+ · Apple Silicon

修复本地会话索引在 WAL 辅助文件不存在时无法读取的问题。恢复会话仍沿用原始数据库和所选账号，不修改会话内容；SQLite 可按需创建协调文件，SQL 查询保持只读。

部分索引不可读时，不再误报指定会话不存在。新增检查覆盖无 WAL/SHM 文件时连续恢复同一会话，并验证 `--yolo` 参数保留及数据库内容未变。

账号列表以更淡的背景、细边框和“✓ 当前账号”标记突出当前 CLI 账号，适配深浅色外观。主窗口默认宽度从 740 缩至 700，略大于最小宽度 680；默认高度保持 470。首次应用较窄布局后，仍记住用户手动调整的窗口尺寸。

下载 DMG 后将应用拖入 Applications。此版本采用临时签名，未进行 Apple 公证。
