macOS 26 及以上 · Apple Silicon（M 系列）· 未公证预览版。

下载 `.dmg`，打开后将应用拖入 Applications。`.sha256` 用于核对下载文件。

此版本使用临时签名，未进行 Apple 公证。首次打开被系统阻止时，可在“系统设置 → 隐私与安全性”核对应用来源后选择“仍要打开”，无需关闭系统安全保护。

支持账号与额度管理、菜单栏快捷切换、跨账号恢复本地会话、原生玻璃背景与透明度设置。需要另外安装官方 Codex CLI；桌面切换仅支持 README 中列出的官方桌面版本。

数据保存在本机。升级时覆盖应用即可，账号和会话数据不会因替换应用包而删除。

本次更新：提供可选 zsh 接入。首次 source 应用内 `Contents/Resources/codex.zsh` 后，普通 `codex` / `codex resume` 每次读取软件当前账号；无需重开终端，旧会话仍可跨账号恢复。配置步骤见 README。

修复额度条布局：不同账号使用一致的轨道宽度，刷新时额度、重置时间或周期数量变化不再改变轨道长度，仅更新剩余比例。

新增额度自动刷新：菜单栏应用运行时，所有已添加账号约每 30 秒更新；忙碌时延后，查询失败保留上次结果并限制重试频率。

新增与菜单栏一致的三环桌面图标，替换默认应用图标。

菜单栏新增固定额度周期选择（5 小时／每周／同时显示），选择自动保存；缺失周期显示 —。自动刷新集成测试不再创建菜单栏图标，避免模拟账号干扰真实界面。
